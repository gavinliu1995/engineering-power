# Onboarding focus

Load this reference when the user requests onboarding, a reading guide, setup
help, modification guidance, or a repository tour.

Deepen the base report with:

1. A reading order from product contract to entry point to domain logic
2. Supported local setup and verification commands
3. Configuration and required external dependencies
4. A change map: common task to responsible module and test
5. Debugging entry points, logs, health checks, and common failure modes
6. Questions a new engineer must clarify before changing core behavior

Separate commands that exist from commands actually executed during analysis.
Avoid copying a README wholesale; reconcile documentation with implementation
and call out material drift.
